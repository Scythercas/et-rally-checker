# ETラリー 走行シミュレータ

ETロボコン2026の難所のひとつ「ETラリー」について、走行指示を基に走行体がどう動くかをシミュレーションするブラウザアプリです。

分かりやすさのため、走行体の代わりにパックマンの画像を、走行ルートはパックマンが食べるクッキーの画像で表しています。

## バージョン

- **無印版**（このディレクトリの `index.html`）: 走行指示は「左」「右」「直進N」のみ対応。
- **v2（機能追加版）**（[`v2/index.html`](v2/index.html)）: 上記に加えて「バックN」（向きを変えずにNマス後退）に対応。無印版のファイル・URLはそのまま維持し、v2は別ディレクトリとして追加公開しています。

以下の「使い方」「走行指示」「できること」は無印版の説明です。v2の差分は [`docs/設計書_v003.md`](docs/設計書_v003.md) を参照してください。

## 使い方

`index.html` をブラウザで開くだけで動きます。インターネット接続もサーバも不要です。

1. コース（L/R）、座標表示、クッキー表示を切り替える
2. ゲートとパックマンをドラッグして配置し、パックマンの向きを決める
3. 走行指示を入力する
4. 「シミュレーションを開始」を押す

## 走行指示

1行に1つ、以下のいずれかを記載します。空行が指示の終わりです。

| 指示 | 動作 |
| --- | --- |
| `左` | 反時計回りに90度回転する |
| `右` | 時計回りに90度回転する |
| `直進N` | 向いている方向にNマス進む（例: `直進5`） |

`samples/InstructionsSample.txt` にサンプルがあります。

「円弧」から始まる行は実機の走行指示には存在しますが、本シミュレータでは未対応のため、その旨を表示します。
それ以外の解釈できない行は、走行指示が不適切である旨を表示します。

## できること

- ゲートの足があるマスは通行できません。衝突する走行指示の場合、その手前で停止して通知します。
- コース外に出る場合は、コースの端で停止して通知します。
- パックマンがくぐったゲートを、くぐった順に表示します。
- ETラリーの課題ポイントを「現在の得点 / 最大の得点」の形式で表示します。
  赤→青→黄の順に通過すると1周回が成立し、1周回=5点／2周回=10点／3周回=15点です（競技規約 5.17.3・6.4 に基づく）。
- 実行速度は 0.25〜4.00 倍の範囲で、実行中でも変更できます。

## ファイル構成

| パス | 内容 |
| --- | --- |
| `index.html` / `style.css` / `script.js` | 無印版アプリ本体 |
| `v2/` | v2（機能追加版）アプリ本体。画像は `images/` を共有する |
| `images/` | コース・ゲート・パックマンの画像 |
| `samples/` | 走行指示のサンプル |
| `docs/設計書_v002.md` | 無印版の設計書 |
| `docs/設計書_v003.md` | v2の設計書（v002からの差分＝バックNを明記） |
| `tests/test_logic.js` | 無印版ロジックの自動テスト |
| `tests/test_logic_v2.js` | v2ロジックの自動テスト |

## テスト

```
node tests/test_logic.js      # 無印版
node tests/test_logic_v2.js   # v2（機能追加版）
```

走行指示の解析、ルート算出、ゲートの足への衝突、コース外での停止、ゲートの通過判定、回転の整合を検証します。
v2側のテストはこれに加えて「バックN」（向きを変えずにNマス後退）の解析・移動・停止・ゲート通過判定を検証します。
